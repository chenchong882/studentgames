# 殭屍堡壘戰鬥與補給改版計畫

日期：2026-07-30（Asia/Taipei）

## 改版目標

1. 讓困難模式的特殊敵人依波次逐步登場，形成可預期但持續升高的壓力。
2. 修正殭屍貼近玩家後無法射中的問題。
3. 彈藥完全耗盡時提供槍託近戰與擊退手段。
4. 在驚喜箱加入快速藥水，強化移動與跨越小型路障的能力。
5. 強化 BOSS 半血進入第二階段時的最終屍潮演出。

## 確認規格

### 困難模式特殊敵人

特殊敵人採「場上存活目標數」，不會在每波無條件重複累加。

| 波次 | 弓箭手目標數 | 殭屍狗目標數 |
|---|---:|---:|
| 1 | 0 | 0 |
| 2 | 2 | 0 |
| 3 | 2 | 2 |
| 4 | 3 | 2 |
| 5 | 3 | 3 |
| 6 | 4 | 3 |
| 7／BOSS | 4 | 4 |

- 殭屍狗正常速度：`6.0`，略慢於玩家的 `6.5`。
- 殭屍狗傷害：`10`。
- 普通殭屍傷害維持 `10`。
- 弓箭手箭矢傷害維持 `14`。

### 近距離射擊與槍託

- 將第一人稱槍模型排除在射擊命中物件之外，縮短射線最近判定距離。
- 彈匣與備用彈藥都為 `0` 時，原本的攻擊操作改為槍託。
- 槍託距離約 `2.2` 公尺、傷害 `1`、冷卻 `0.65` 秒，並強力推開命中的殭屍。
- 手機和平板沿用原本攻擊按鈕，無彈藥時按鈕文字改為「槍託」。
- 有備用彈藥時仍優先換彈，不觸發槍託。

### 快速藥水

- 驚喜箱獎勵由 5 種增加為 6 種，各獎勵等機率出現。
- 效果持續 `15` 秒。
- 走路速度增加 `50%`：`6.5 → 9.75`。
- 跳躍初速提升為 `9.0`，可跳上現有 `1.5` 公尺矮牆，但無法跳上房屋。
- 強化狀態列顯示剩餘秒數。

### BOSS 第二階段最終屍潮

- BOSS 半血、第二次開啟護盾時，不分模式生成最後 `6` 隻普通殭屍。
- 困難模式不再額外補特殊敵人，避免和當時最多 4 名弓箭手、4 隻殭屍狗疊加失控。
- 顯示中央警告：「BOSS 發出震天怒吼！最後一批殭屍從四面八方湧來了！」
- 任務列持續提示玩家守住正確小屋、破除第二護盾。

## 驗收清單

- [ ] 困難模式第 2～7 波的弓箭手與殭屍狗符合目標數量。
- [ ] 殭屍狗正常追擊速度比未喝藥的玩家稍慢，單次傷害為 10。
- [ ] 貼近殭屍仍可正常射擊命中。
- [ ] 彈藥完全歸零後，桌機與觸控操作都能使用槍託並擊退敵人。
- [ ] 快速藥水可提升速度與跳躍力 15 秒，能翻越 1.5 公尺矮牆但不能上房。
- [ ] BOSS 半血時出現最終屍潮文字並生成 6 隻普通殭屍。
- [ ] 外部題庫的 hash、postMessage 與欄位正規化鏈未受影響。
