# 共用開始與暫停介面

適用主站 9 款遊戲。記憶翻牌獨立專案不在本次範圍。

## 使用流程

- 8 款選答遊戲：課程與字數 → 練習題型（中英文字／圖片題／混合練習）→ 遊戲難度（簡單／困難）→ 開始遊戲。主要區域為 6 顆按鈕；返回與玩法說明另列。
- 單字獵人沿用固定 3 關的找字玩法，顯示課程摘要，不新增無作用的圖片或難度按鈕。
- 操作難度不再改變文字與圖片的分配。混合練習依遊戲的回合／題庫產生方式混合，不承諾每局圖片數恰為一半。
- 圖片需有互異可辨識圖案：一般至少 4 個，狙擊至少 5 個。外部課程也依此條件開放；純圖片模式只使用可辨識圖片的單字。炸彈純圖片模式先過濾關卡單字，避免混進缺圖詞。
- 無圖／圖片不足時停用圖片與混合選項，明示改選文字；保留偏好供下一份支援的題庫使用。
- 狙擊句子題、海岸例句、攻防文法／填空、殭屍聽音練習、坦克操控設定收進進階設定，各自記住選擇。
- 暫停按鈕固定右上，48 × 48 CSS px。選單統一為「繼續遊戲／重新開始／返回遊戲選單」。
- 「重新開始」會確認結束本局，保留題庫及設定後重新載入開始畫面，仍由學生點擊真實開始按鈕解鎖音效／發音。

## 實作與相容

`game-setup.js` 提供共用 DOM 與偏好；各遊戲提供能力、難度和玩法說明 adapter。既有開始按鈕的 click、語音解鎖與資料 hash／message 入口保留。炸彈原 Canvas 開始／暫停改為 DOM，遊戲場景保持原樣。

`lesson-data.js` 額外保留最後載入資料與通知；重載沿用課程內容。首頁、正式題庫檔案來源與分享連結格式這次未改，資料庫串接仍待另外定案。

## 靜態驗證

9 份 HTML 的共用腳本載入順序、ID 唯一性、主要 adapter 元素對應均核對。11 個 JavaScript 檔案／內嵌程式區塊通過 `node --check`。海岸簡單模式 BOSS 0.6 倍速度保留。

## 請用實機確認

1. 手機橫式、平板橫／直式進入各款開始畫面：只有一套主要設定，能捲到開始鈕，文字不互相遮住。
2. 同一份附圖題庫選文字／圖片／混合各開一局；切簡單／困難仍維持該題型。海岸及攻防包含 BOSS；炸彈含缺圖詞的題庫以純圖片開始。
3. 無圖或狙擊僅 4 個圖案：圖片選項停用，有明確原因。
4. 暫停後繼續；再暫停選重新開始：課程與設定保留，新一局的音效與發音正常。
5. 開啟進階句子、文法或聽音設定；切換難度時內容選擇不被改掉。
6. iPhone／iPad 點開始與重聽，確認發音；Windows／Mac 以滑鼠與鍵盤操作設定、暫停。
